# Security policy

## Supported versions

Before the first tagged release, security fixes are made on `main`. After release, the latest tagged minor release receives security fixes. Older `0.x` minor releases are not supported unless a release note says otherwise.

| Version | Supported |
| --- | --- |
| `main` | Yes, before the first release |
| Latest tagged minor | Yes |
| Older tagged minors | No |

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/moneycaringcoder/herdr-crook/security/advisories/new). Do not open a public issue.

Include:

- affected Crook version or commit;
- affected operating system;
- a minimal reproduction or proof of concept;
- expected and observed behavior;
- impact and any known mitigations.

Do not include production credentials, tokens, private data, or unrelated repository content. Reports will be handled privately until a fix and disclosure plan are ready.
